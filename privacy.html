Informativa sulla privacy

Aggiornata il 23 ottobre 2026

Chi siamo

C.L.E.F. è un’applicazione desktop personale sviluppata e usata da una sola persona (lo sviluppatore, che è anche l’unico utente), sul proprio computer. Contatto: lorenz.benassi@gmail.com.

Quali dati Google usa e perché

L’app accede soltanto all’account Google dello sviluppatore, con il suo consenso, per questi scopi:

  • Gmail: leggere l’elenco delle mail non lette (mittente, oggetto, anteprima) e, solo su richiesta dell’utente, il testo di una singola mail per riassumerlo o rispondere a domande sul suo contenuto. L’app non invia, non risponde, non cancella e non archivia mail, e non apre gli allegati.
  • Google Calendar: leggere gli eventi del calendario principale; creare, modificare o cancellare un evento solo dopo una conferma esplicita dell’utente.
  • Google Sheets: leggere il foglio delle finanze personali; aggiungere una riga solo dopo una conferma esplicita dell’utente.

I dati servono esclusivamente a rispondere alle richieste dell’utente dentro l’app.

Come vengono trattati

  • L’app e lo strumento di automazione che la collega a Google (n8n) funzionano sul computer dell’utente. Lo sviluppatore non ha un server che raccoglie o conserva dati Google.
  • I dati Google non vengono venduti, ceduti o condivisi con terzi, non vengono usati per pubblicità e non vengono letti da persone diverse dall’utente stesso.
  • Quando l’utente chiede un riassunto di una mail o fa una domanda in chat, il testo necessario a rispondere (per esempio il testo di quella mail) viene inviato al servizio API di OpenAI per generare la risposta, secondo le condizioni d’uso di OpenAI. Questo avviene solo su richiesta dell’utente.
  • Le conversazioni con l’assistente sono salvate in un file sul computer dell’utente. Il registro tecnico dell’app non contiene il testo delle mail. Lo strumento n8n può conservare in locale lo storico delle proprie esecuzioni.

Google API Services User Data Policy

L’uso e il trasferimento a qualsiasi altra app delle informazioni ricevute dalle API di Google rispetta la Google API Services User Data Policy, compresi i requisiti sull’uso limitato (Limited Use).

Revoca dell’accesso e cancellazione

L’accesso si può revocare in qualsiasi momento da myaccount.google.com/permissions. I dati locali (cronologia delle chat e registri) si cancellano eliminando i file dell’app dal computer.

Modifiche

Questa informativa può essere aggiornata; la data in alto indica l’ultima versione.

Privacy Policy (English)

Last updated: 23 October 2026

C.L.E.F. is a personal desktop application built and used by a single person (the developer, who is also the only user) on their own computer. Contact: lorenz.benassi@gmail.com.

Google data accessed and why

With the owner’s consent, the app accesses only the developer’s own Google account: it reads the list of unread Gmail messages and, only on request, the text of a single message in order to summarize it or answer questions about it; it reads Google Calendar events and creates, changes or deletes an event only after explicit confirmation; it reads a personal finance Google Sheet and appends a row only after explicit confirmation. It never sends, replies to, deletes or archives email and never opens attachments. Data is used only to answer the user’s own requests inside the app.

How data is handled

The app and the automation tool that connects it to Google (n8n) run on the user’s own computer; the developer operates no server that collects or stores Google data. Google user data is not sold, transferred or shared with third parties, is not used for advertising, and is not read by anyone other than the user. When the user asks for a summary or asks a question in the chat, the text needed to answer (for example the text of that email) is sent to the OpenAI API to generate the answer, under OpenAI’s terms; this happens only on the user’s request. Chat history is stored in a file on the user’s computer.

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
